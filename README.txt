HOW TO PERSONALIZE
1. Open index.html in a text editor and edit the CONFIG block near the bottom:
   your name (fromName), the letter, photo captions, wish.
   Birthday is set to 29 Nov 2007, so the surprise unlocks on 29 Nov 2026.
2. Photos are in /photos (1.jpg, 2.jpg, 3.jpg). Song is /music/song.mp3.
3. To open it early, tap "I have a secret code" on the first screen and enter the code.

PRIVATE LINK
Upload this folder to Netlify Drop (app.netlify.com/drop), Vercel or Cloudflare Pages.
You get a random URL, and the page has noindex so search engines won't list it.
The lock uses the phone's own clock, which is fine for a surprise.
